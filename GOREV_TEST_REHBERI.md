# Görev Test Rehberi – Okey masası yatay

## A. Güncelle (yeni paket var, kurulum şart)
1. `git pull origin claude/kind-goodall-dy5z7y`
2. `cd app`, sonra `npm install` (ekran döndürme paketi eklendi)
3. `npx expo start -c --tunnel`

## B. Deneme
1. Oyunlar > **Okey** ya da **101 Okey** > **YAN YANA** → masa aç. Bekleme odası **dikey** kalır.
2. **Deneme oyuncusu ekle** → **Oyunu başlat**: ekran kendiliğinden **yana döner**, telefonu yatay tut.
3. Altta ortada ıstaka, solunda **Yandan al**, sağında **Taş at**; üstte masa (karşı ve yan oyuncular, deste, gösterge).
4. Taşı sürükleyip **Taş at**’a bırak; desteye dokunup çek. 101’de **Ortayı gör** destenin yanında.
5. El sonu ve oyun sonu tabloları da yatay açılır.
6. Masadan çıkınca (çarpı ya da Oyunlara dön) uygulama yeniden **dikey** olur; diğer ekranlar dönmez.
